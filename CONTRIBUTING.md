# Contributing

Open a pull request with a focused change, reproduction and regression test.
Run `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`
and `cargo test --workspace --locked` before requesting review.

The repository is licensed under `LICENSE`. There is currently no administered
Contributor License Agreement (CLA). Do not claim that contributors have signed
one or that their contributions grant additional commercial relicensing rights.
Any future CLA and treatment of existing contributions require a separate,
explicit process; a documentation change is not a signed agreement.

For vulnerabilities, follow `SECURITY.md` instead of opening a public issue.

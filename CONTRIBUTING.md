# Contributing

Open a pull request with a focused change, reproduction and regression test.
Run `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`
and `cargo test --workspace --locked` before requesting review.

## Contributor License Agreement

The repository is licensed under `LICENSE` (AGPL-3.0-or-later). Before a pull
request can be merged, every author signs the
[Contributor License Agreement](CLA.md) once. On your first pull request the
CLA assistant asks you to post this comment:

> I have read the CLA Document and I hereby sign the CLA

Signatures are recorded on the `cla-signatures` branch. If you contribute on
behalf of an employer, your employer signs the Entity agreement in `CLA.md`
first.

What you agree to: you keep the copyright in your contribution and grant the
project owner a licence to use it, including the right to also offer it under
licence terms other than the AGPL (for example to an appliance vendor). The
project promises that accepted contributions stay available under the
AGPL-3.0-or-later in the public repository.

Until the CLA workflow is enabled, pull requests from outside contributors are
not merged. Opening a pull request or editing this file is not a signature.

## Security

For vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
For help, see `SUPPORT.md`.
